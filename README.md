## What is CGP?

**The Blueprint for Digital Sovereignty.**

CGP is a tokenless, forkable chat protocol inspired by Bitcoin’s data integrity but built for structured communities. It solves the discovery vs. sovereignty paradox by decoupling global discovery from sovereign community hosting.

-   **Sovereign Communities**: Your community is an asset you own, not a service you rent.
-   **Cryptographically Secured**: Every action is an event in a hash-linked log.
-   **Forkable Governance**: If a host goes rogue, you can fork the entire community history to a new relay.
-   **Omni-Frontend**: The same underlying data can render as a guild-based server, a stream-based chat, or a forum.

## Project Setup

This website is built with **React** and **Vite**, using **Tailwind CSS** for styling.

### Prerequisites

-   Node.js (v16+)
-   npm

### Installation

```bash
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

### Build

Build for production:

```bash
npm run build
```

The output will be in the `dist` directory.
